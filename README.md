# Vida Terrestre

Plataforma web educativa voltada à conscientização, preservação e valorização da biodiversidade terrestre.

## Sobre o projeto

O **Vida Terrestre** é um projeto desenvolvido como parte do **Projeto Integrador do curso de Desenvolvimento Web da Faculdade Senac Criciúma**.

A plataforma tem como objetivo apresentar informações sobre fauna, habitats e conservação ambiental no Brasil, contribuindo para a conscientização sobre a importância da preservação dos ecossistemas terrestres.

O projeto está alinhado ao **Objetivo de Desenvolvimento Sustentável 15 (ODS 15)** da Organização das Nações Unidas (ONU), que busca proteger, restaurar e promover o uso sustentável dos ecossistemas terrestres.

## Objetivos

- Promover a conscientização sobre a biodiversidade.
- Apresentar informações sobre espécies da fauna brasileira.
- Incentivar a preservação dos ecossistemas terrestres.
- Facilitar o acesso a informações ambientais.
- Desenvolver uma experiência educativa e interativa.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## ODS 15 – Vida Terrestre

O projeto está relacionado à **ODS 15 – Vida Terrestre**, um dos Objetivos de Desenvolvimento Sustentável estabelecidos pela Organização das Nações Unidas.

A ODS 15 busca proteger, restaurar e promover o uso sustentável dos ecossistemas terrestres, combater a desertificação, interromper a degradação da terra e contribuir para a preservação da biodiversidade.
